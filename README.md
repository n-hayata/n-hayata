## About

株式会社トリプルスリーで取締役CTOを務めています。2018年創業、外食産業向けのHR-techを手がける会社で、導入は100社を超えました。職種を問わず全員がAIを使い倒す前提で組織を組み直していて、少人数のまま扱える範囲をどこまで広げられるかに関心があります。日々の実践は [Tech Blog](https://zenn.dev/p/triplethree) に書いています。

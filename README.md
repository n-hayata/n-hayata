### やっていること

- 🏢 **株式会社トリプルスリー（TRIPLE THREE）** — 外食産業向けのHR-tech企業（2018年創業・約50名）
- 🍽️ 採用・教育・定着・ブランドまで、外食企業の人財課題全体をカバーする**9つのSaaSプロダクト**を開発 — 導入**100社超**
- ⚡ プロダクトチームは**エンジニア4人＋デザイナー1人**。少人数×AI前提の開発体制で回すのが持ち味
- 🧭 担当領域: プロダクト開発／技術戦略／技術組織の設計／コーポレートIT

### TRIPLEシリーズ

| プロダクト | 内容 |
| --- | --- |
| **TRIPLE REPORT** | QSC臨店チェックと改善レポートの自動化 |
| **TRIPLE RECRUIT / REFERRAL** | 飲食業向けの採用管理・リファラル採用 |
| **TRIPLE ONBOARDING** | 店舗マニュアルの作成・教育運用 |
| **TRIPLE ENGAGEMENT** | 従業員エンゲージメントサーベイ |

ほかにも → [333-inc.com](https://333-inc.com/) — ちなみに[自社の採用ページ](https://333-inc.tt-recruit.com/)も自社プロダクトのTRIPLE RECRUITで動いています。
